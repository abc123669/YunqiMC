# YunqiMC 0.1.0-alpha.1 使用说明

YunqiMC 是基于 Paper 的 Minecraft Java Edition 1.21.11 服务端。此版本是
**开发预览版**：已经完成基础启动与部分兼容检查，尚未完成长期稳定性和正式性能验收。

## 启动

1. 安装 64 位 Java 21，建立独立服务端目录，将 YunqiMC 服务端 JAR 放入。
2. 在该目录运行 `java -Xms1G -Xmx4G -jar yunqimc-server-1.21.11-0.1.0-alpha.1.jar --nogui`。
   按实际内存调整参数，并为系统、直接内存、代理及插件保留空间。
3. 首次运行后阅读生成的 `eula.txt` 所链接的 Minecraft EULA；同意后按文件提示修改，再启动服务端。
4. 在控制台使用 `stop` 正常保存并关闭。升级或迁移现有世界前，先停止服务并验证备份可恢复。

若使用 Velocity，按 Paper 与 Velocity 的官方说明设置 Modern Forwarding、
两侧相同的密钥及后端访问限制；密钥不要放入公开文档或诊断包。

## 配置与诊断

YunqiMC 首次启动创建 `yunqimc.yml`，保留 Paper 原有配置文件。默认关闭
`network.flush-consolidation.enabled` 实验项；启用或修改阈值后须重启。
实验项尚未通过完整性能及插件矩阵验收。
`diagnostics.network.sample-rate` 指定写入完成时间的采样间隔，默认为 64；
设为 0 可关闭这项采样。配置修改在重启后生效。

控制台或具备 `yunqimc.admin` 权限的管理员可使用：

- `/yunqimc version`：显示 YunqiMC 与 Minecraft 版本。
- `/yunqimc status`：显示实验项、可用处理器数和实际网络压缩/加密后端。
- `/yunqimc network`：显示自启动以来的网络聚合计数。
- `/yunqimc diagnostics`：在服务端目录写入不包含配置密钥的诊断快照。

网络写入字节是提交至传输管线的字节数，写入完成耗时是服务端管线的时间；
它们不代表客户端确认收到的数据量或客户端实际延迟。
不可写时间是各连接已结束的不可写区间之和；仍在持续的区间会在恢复可写或
连接关闭后计入。
现阶段不提供 YunqiMC 自动更新服务。

## 兼容性范围

YunqiMC 保留 Bukkit、Spigot 和 Paper 公共 API 与 Paper 的主线程模型。
插件兼容仍需按具体版本验证，特别是直接访问服务端内部实现的插件。
完整兼容矩阵、异常恢复、持续运行和性能比较仍在进行。
