# YunqiMC

**YunqiMC — An Independent High-Performance Minecraft Server Core**

基于 Paper 的 Minecraft Java 1.21.11 服务端，兼容 Bukkit、Spigot、Paper 插件。

## 测试版

[下载 0.1.0-alpha.1 测试版](../../releases)（Java 21）。请在独立测试环境使用，先备份世界和插件；实验性网络 flush 合并默认关闭。

已在本机验证启动、机器人登录、世界保存及重启、LuckPerms、ProtocolLib，以及 Velocity Modern Forwarding 的基础连接和跨服。长期稳定性、完整插件兼容矩阵和配对性能对比尚未完成；目前没有性能优势结论。

源码及构建说明包含在发行版的源码压缩包中。请在 Issues 报告可复现问题，分享日志前去除 IP、凭据和私人数据。
